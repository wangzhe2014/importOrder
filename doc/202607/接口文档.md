# 异步导入接口

## POST `/api/import-tasks`

`multipart/form-data`，字段：`file`、`rule`。`rule` 为已确认的 V2 解析规则 JSON。

响应：

```json
{
  "task_id": "task_xxx",
  "trace_id": "trace_xxx",
  "status": "pending",
  "total_rows": 10000,
  "total_batches": 10,
  "batch_size": 1000
}
```

## GET `/api/import-tasks/:taskId`

返回状态、总行数、处理行数、成功/失败行数、批次进度、吞吐、ETA、降级状态和最近错误摘要。

## GET `/api/import-tasks/:taskId/errors`

查询参数：`batch`、`error_code`、`page`、`page_size`。`page_size` 最大 200。

导出失败明细：`GET /api/import-tasks/:taskId/errors?format=csv`。

## GET `/api/import-tasks/:taskId/batches`

查询批次状态和 `parse_duration_ms`、`rule_duration_ms`、`validate_duration_ms`、`insert_duration_ms`、`total_duration_ms`。

## GET `/api/traces/:traceId`

返回按时间排序的 Trace 时间线。可附加 `task_id`、`unit_id`、`batch` 筛选。

## GET `/api/import-monitor/summary`

返回最近 5 分钟吞吐、队列积压、阶段耗时 P50/P95/P99、错误分布和慢批次 TOP10。

## POST/GET `/api/cron/outbox`

投递 `event_outbox` 中 pending 或到期 failed 事件。生产环境可由 Vercel Cron 调用，本地由 Worker 内置轮询。
